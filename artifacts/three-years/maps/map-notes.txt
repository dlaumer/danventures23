Maps use the same 30 September 2026 database snapshot as the statistics slides, through 29 September 2026. Source geometry: legs.json, simplified by the API at 0.01 degrees. Each transport mode uses its exact colour from frontend/src/constants.ts on the original website. Paid transport is drawn first, then all free transport (car, truck, boat, friends, bike and foot) on top, using the website classification. Flights are dashed and shown only when both endpoints fall inside a regional view. Europe uses a separately scaled Iceland inset; the Africa slide includes a Canary Islands detail inset. Boundaries: Natural Earth, via github.com/datasets/geo-countries. Country colouring provides context, not a country-count definition. Western Sahara is labelled separately. Routes show the stored geometry; they are not reconstructed travel paths.
